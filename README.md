# 方寸游戏馆

33 款无需安装、打开即玩的中文网页游戏，以及 4 个多人竞技项目入口，统一收纳在一个三层以内的站点中：

1. 首页
2. 分类页（逻辑推理、数字棋盘、休闲挑战、多人竞技）
3. 游戏播放页

## 本地使用

直接双击 `index.html`，或用任意静态文件服务器打开当前目录。

## 发布

站点不需要构建步骤，可直接托管在 GitHub Pages。所有原始游戏仍是独立 HTML，统一入口通过 iframe 嵌套，不改变原游戏逻辑。

多人竞技区分为两类：OpenFront.io、Blockyard 使用项目公开服务器并在新窗口运行；GameNest、BattleBox 需要独立部署持续在线的 Node.js 服务端。GamePix 与 GameDistribution 需完成发布商登记、取得授权链接后再导入。
